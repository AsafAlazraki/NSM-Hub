# **App Name**: NSM Service Quotation

## Core Features:

- Quote Dashboard: Dashboard display of existing quotes as cards, showing key details.
- Quote Creation Form: Multi-step form for creating a new service quotation with sections for user details, customer/boat information, and operations.
- User & Reference Input: Form fields to capture user's personal details and our reference, retrieved automatically from the user's profile. Allows user verification.
- Customer & Boat Data Input: Capture customer's name, address, phone, boat/motor/trailer details, and insurance reference.
- Operation Details Input: UI for adding labor (description, rate, hours) and parts (name, cost, ability to add multiple parts) to each operation. Dynamic calculation of labor cost.
- Quote Summary & Edit: Summary screen displaying all entered data (user, customer, boat, operations) for review and editing before quote generation.
- Quote PDF Generation: Generate a polished PDF document for customer delivery. The tool will intelligently arrange quote data, incorporate the company logo, and use the brand's colors appropriately to match brand identity, resulting in a professional and visually appealing quotation.

## Style Guidelines:

- Primary color: Soft blue (#78A0D6) to convey trustworthiness and professionalism, with a hint of technological feel.
- Background color: Very light blue (#EAF0F8) for a clean, uncluttered appearance, fitting for a form-driven UI.
- Accent color: Pale green (#8DCDB5) to provide contrast for actionable items without overwhelming the user.
- Headline font: 'Space Grotesk' sans-serif for a tech-forward and clear aesthetic.
- Body font: 'Inter' sans-serif, to complement 'Space Grotesk', for readability in forms and summaries.
- Clean and simple line icons representing actions (add, edit, generate) and data categories (user, customer, boat).
- Use of cards to display existing quotes and operations, providing a clear visual hierarchy and scannability.
